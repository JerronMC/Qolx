Why Qolx

Less code to say the same thing. Every feature below works in this release.

Easy to read

Indentation-based, plain words. button "Add" -> count += 1 does what it says.

Fast and tiny

Compiles to one static HTML file with a ~1 KB reactive runtime. No framework, no build step.

Beginners and pros

Start with six words. Drop into real JavaScript expressions, functions and custom CSS when you need power.

The .qolx format

One file is an app. Open it in a browser with run.html just like opening an HTML page.

Projects

A qolx.json describes name, version, entry file and targets. The Create App tool writes it for you.

Mobile and desktop UI

Responsive layouts and a light or dark theme come built in. Same file on phone, tablet and desktop.

Same app, less code

A counter in plain HTML + JavaScript versus Qolx.

index.html
<div id="app">
  <h1>Counter</h1>
  <p>Clicked <span id="n">0</span> times</p>
  <button id="b">+1</button>
</div>
<script>
  let count = 0;
  const n = document.getElementById("n");
  document.getElementById("b")
    .addEventListener("click", () => {
      count++; n.textContent = count;
    });
</script>

Language reference

Lines nest by indentation (2 spaces). {expr} inside text is live. -> runs code on click.

WordExampleWhat it does
appapp "My App"Sets the app title
theme / accenttheme light · accent #10b981Light or dark, and the main color
statestate count = 0A reactive value. The screen updates when it changes
fnfn reset = count = 0Reusable action. Call it with reset()
page, card, row, column, gridgrid cols=3 gap=12Layout containers
title, heading, texttext "Hi {name}"Text, with live values
buttonbutton "Add" -> n += 1Runs the code after -> when clicked
input, checkboxinput name hint="Your name"Two-way bound to a state value
ifif count > 5Shows its children only when true
image, link, divider, spacelink "Docs" to="/docs"Media, navigation and spacing
canvas, loop, keycanvas w=360 h=560 -> flap()Games: a canvas (ctx, W, H are ready), a loop block run every frame with dt, and key Space -> fn(). Multi-line fn name(args) blocks are indented code
stylestyle .q-btn{border-radius:99px}Raw CSS escape hatch
Propsgap= pad= width= color= bg= size= radius= align=Quick styling on any element
