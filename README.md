# Qolx
A small language that compiles `.qolx` files into fast, reactive web apps, with project export for Android, iOS, Windows, macOS and Linux.

## Publish on GitHub Pages
1. Create a repo and upload everything in this folder to `main`.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Open `https://<you>.github.io/<repo>/`.

## Files
`index.html` landing + docs · `playground.html` live editor · `build.html` Create App · `run.html?file=x.qolx` open a .qolx file · `qolx.js` the compiler · `` sample .qolx files
